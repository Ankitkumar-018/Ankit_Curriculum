# Curriculum — pre-reads and lecture scripts

Published course content. Each batch is a top-level folder (batch id from the INI sheet).

## Repository layout

```
├── README.md
├── templates/
│   ├── pre-read-template.md
│   └── lecture-script-template.md
├── <batch-id>/
│   ├── module-01-<topic>/
│   │   ├── lecture-01-<topic>/
│   │   │   ├── pre-read.md
│   │   │   ├── lecture-script.md
│   │   │   ├── data/          # optional
│   │   │   └── images/        # optional
│   │   └── ...
│   └── ...
└── ...
```
